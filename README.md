## 📌 Sobre o Projeto
Este repositório contém a entrega do **Challenge JOVI** do curso de **Análise e Desenvolvimento de Sistemas (ADS)** da **FIAP**. 

O projeto foi desenvolvido em resposta a um desafio real proposto pela empresa **JOVI** em parceria com a FIAP. A proposta consistiu na concepção e implementação de uma solução web focada na experiência do usuário (UX/UI) e integrada a conceitos de **Inteligência Artificial**, visando resolver problemas estratégicos e otimizar os processos da JOVI.

---

## 🛠️ Tecnologias Utilizadas

- **HTML5:** Estruturação semântica da aplicação web.
- **CSS3 / Tailwind CSS / Bootstrap:** Estilização responsiva e componentes interativos de UI/UX.
- **JavaScript (ES6+):** Lógica da aplicação, manipulação do DOM e integração com conceitos/APIs de Inteligência Artificial.
